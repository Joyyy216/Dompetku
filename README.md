# DompetKu 💳

Aplikasi pencatat keuangan sederhana (Expense Tracker) menggunakan React Native dan Expo.

## 📌 Fitur
- Menambah transaksi pemasukan
- Menambah transaksi pengeluaran
- Menampilkan total saldo
- Riwayat transaksi menggunakan FlatList
- Warna hijau untuk pemasukan
- Warna merah untuk pengeluaran

## 🛠️ Teknologi
- React Native
- Expo
- JavaScript
